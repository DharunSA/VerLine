# 🎨 VerLine Design Theme — Golden Heirloom

Derived from the reference visual artwork (`src/assets/Family_tree.jpeg`), the **Golden Heirloom** theme captures the magical, deep-rooted atmosphere of an ancient illuminated family tree.

---

## 🎨 Color Palette

| Token Name | Hex / Value | Inspiration & Usage |
| :--- | :--- | :--- |
| **Canvas Background** | `#12161A` | Deep atmospheric slate-charcoal representing the shaded forest floor |
| **Surface 0 (Base)** | `#161C22` | Deep bark container background |
| **Surface 1 (Card)** | `#1E262F` | Elevated glass card surface with subtle transparency |
| **Surface 2 (Border)** | `#2A3440` | Subtle glowing bark border & structural dividers |
| **Amber Glow (Primary)**| `#E5A93C` | Warm firefly illumination & primary interactive highlights |
| **Amber Dark** | `#B47820` | Golden bronze state active & hover tones |
| **Emerald Leaf (Secondary)**| `#3A755C` | Lush leaf canopy accent for extension branches & badges |
| **Sage Highlight** | `#5E8B7A` | Soft leaf highlights and extended kinship indicators |
| **Parchment Cream (Text)**| `#FAF7F2` | High-contrast heirloom primary text |
| **Warm Muted (Subtext)**| `#A0AEC0` | Secondary descriptions, dates, and generation badges |

---

## 📜 Typography Scale

1. **Display / Headings**: `Cormorant Garamond` (Serif) — Elegant, heirloom quality for page titles, member names, and biography titles.
2. **Body & UI Controls**: `Inter` (Sans-Serif) — Clean, legible UI typography for inputs, badges, and controls.
3. **Story & Pull Quotes**: `Caveat` (Handwriting Script) — Warm hand-lettered feel for generated AI family stories and pull-quotes.

---

## ✨ Atmospheric Elements

- **Hero Background**: Low-opacity overlay of `src/assets/Family_tree.jpeg` providing atmospheric depth without obstructing node visibility.
- **Glassmorphism**: Soft background blur (`backdrop-blur-md`) with gold-tinted subtle borders (`rgba(229, 169, 60, 0.15)`).
- **Marriage Edges**: Side-to-side warm amber curves with a glowing heart badge (`♡`).
